# Michael Mesfin | Software Engineer Portfolio

A sleek, responsive, and animated personal portfolio website built with React and Tailwind CSS.

🌍 **Live Demo:** [https://michael-mes-portfolio.netlify.app/](https://michael-mes-portfolio.netlify.app/)

## 🚀 Tech Stack

- **Framework:** React.js + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **UI & Icons:** Radix UI, Devicon & Lucide React

## 🛠️ Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/michael-duke/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Code Quality (Lint & Format):**
   ```bash
   npm run check-all
   ```
