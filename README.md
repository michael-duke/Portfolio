A sleek, responsive, and animated personal portfolio website engineered for performance and beautiful UX.

🌍 **Live Demo:** [https://michael-mes-portfolio.netlify.app/](https://michael-mes-portfolio.netlify.app/)

## ✨ Key Features

- **Custom Animations:** Smooth, 60fps scroll and page transition animations powered by Framer Motion.
- **Interactive UX:** Includes a custom, physics-based spring cursor with dynamic hover states.
- **Modern Architecture:** Built on Vite + React 19 for lightning-fast hot module replacement and optimized builds.
- **Responsive Design:** Fluid layout scaling seamlessly from mobile devices to ultra-wide displays.

## 🚀 Tech Stack

- **Framework:** React.js + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **UI & Icons:** Radix UI, Devicon & Lucide React

## 🛠️ Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/michael-duke/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Code Quality (Lint & Format):**
   ```bash
   npm run check-all
   ```
